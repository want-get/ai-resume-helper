# AI 求职助手（单机版 v3.0）

> 输入求职方向 / 期望城市 / 期望薪资 → **抓取真实中文岗位并算出当地薪资行情**
> → 生成**你专属的知识库** → 基于它做**模拟面试**与**简历优化**。
>
> 单机运行、双击即用、不需要装数据库、不需要改配置文件、不收集任何数据。

---

## 一、怎么用（三步）

### 方式 A：用打包好的 exe（推荐给普通用户）

1. 找到 `dist\AI求职助手.exe`，**双击**
2. 等十几秒（首次要建库），浏览器会自动打开界面
3. 按界面上的步骤条走：填档案 → 传简历 → 抓岗位 → 选目标岗位 → 建知识库 → 开始面试

> 数据写在 exe 同级的 `data\` 目录里（数据库、向量库、日志、你的配置）。
> 想换台电脑用，把整个文件夹拷走即可；想清空重来，删掉 `data\` 就行。

### 方式 B：源码运行（开发/调试）

```bash
pip install -r requirements.txt
python main.py                    # 自动找空闲端口 + 打开浏览器
python main.py --port 8900 --no-browser   # 指定端口、不开浏览器
python server.py --reload         # 只跑后端，改代码自动重启
```

## 二、界面流程（有硬门禁，信息不全不让往下走）

```
① 求职档案 ──► ② 抓岗与薪资 ──► ③ 专属知识库 ──► ④ 模拟面试
   必填项             需要档案完整         需要选定目标岗位        需要知识库就绪
```

| 步骤 | 要做什么 | 门禁 |
|------|---------|------|
| **① 档案** | 求职方向、期望城市、期望月薪下限（**必填**）+ 简历（**必填**） | 缺任何一项，后面所有接口返回 `428` 并告诉你缺什么 |
| **② 抓岗** | 点一下，从真实招聘网站抓岗位并统计薪资 | 需要档案完整 + 模型已配置 |
| **③ 知识库** | 从抓到的岗位里挑一个「设为目标岗位」，再点生成 | 需要已选定目标岗位 |
| **④ 面试** | 出题、逐题作答、生成报告 | 需要知识库已就绪 |

**大模型配置**：右上角「⚙️ 模型设置」，填完点保存**立即生效**，不用改配置文件、不用重启。
支持 DeepSeek / Kimi / 通义千问 / 任意 OpenAI 兼容接口（自建网关、Ollama 等）。

## 三、核心能力

### 1. 定向抓取真实中文岗位

按你的**求职方向**拆出关键字，**只匹配职位名称**（搜公司名不会命中），再按城市过滤。

| 数据源 | 说明 | 薪资字段 | 验证情况 |
|--------|------|---------|---------|
| **牛客网 · 校招 / 社招** | 公开 JSON 接口，多公司聚合 | ✅ 有（结构化字段） | 实测可用 |
| **前程无忧 51job** | 社招，岗位量最大、薪资样本最多 | ✅ 有（数字字段，元/月） | 实测可用，见下方说明 |
| **腾讯招聘官网** | 公司官网一手 JD | ❌ 无 | 实测可用 |
| **网易招聘官网** | 公司官网一手 JD | ❌ 无 | 实测可用 |
| **京东校招** | 公开 JSON 接口 | ❌ 无 | 实测可用 |
| **自定义公司官网** | 你填列表页 URL，用系统 Edge 渲染并自动识别岗位卡片 | 有就抓 | 见下方说明 |

> **关于 51job**：它用阿里云 WAF 挡住了直接请求（httpx 拿到的是一段 JS 挑战页），
> 所以本项目用**真实浏览器渲染 + 拦截页面的 XHR 接口**来取数据，
> 拿到的是结构化 JSON（`jobSalaryMin`/`jobSalaryMax` 是数字，元/月），
> 比去解析「6-8.5千」这类文案可靠得多。
>
> 已知限制：短时间内请求过多会触发**滑动验证**，此时该来源会被跳过，
> 并明确提示「触发了人机验证」而不是悄悄返回 0 条。稍后重试即可。
> 它需要系统 Edge/Chrome，所以容器环境里不可用。

> **关于新增公司官网**：公司数量是无穷的，为每家写代码不现实。
> 本项目提供**配置驱动**的 `json_api` 适配器：只要该公司的招聘页有公开 JSON 接口，
> 填一段配置就能接入（腾讯、网易就是这么接的，可直接照抄改字段名）。
> 注意公司官网基本都**不公开薪资**，它们能丰富岗位和 JD，但薪资样本仍主要来自牛客和 51job。

> **关于自定义官网（通用渲染爬虫）的实测边界**：
> 在**牛客职位广场**上实测通过——能正确抽出职位名、城市、薪资与原文链接。
> 但在**智联招聘**这类 DOM 结构特殊的站点上，自动识别岗位卡片会失败，
> 此时程序会明确告诉你「请配置 `item_selector`」，而不是静默返回空结果。
> 也就是说：**框架可用、单站点需要按需配置**，不是开箱适配所有网站。

> **关于城市代码（51job）**：内置了 31 个城市的区域代码，每一个都是**实测验证过**的
> （用该代码搜索后检查返回岗位的城市是否真的落在目标城市）。
> 早期凭记忆猜的 8 个代码实测都会返回**别的城市**（如「南通」实际返回常熟、
> 「南昌」返回石家庄），已全部剔除——猜错会静默给出错误城市的岗位，最难发现。
> 表里没有的城市会自动退化成「全国检索 + 本地按城市过滤」，结果依然正确。

* 多个来源 **并发抓取**，单个来源失败不影响整体，失败原因如实上报
* **两级抓取**：先抓列表 → 按职位名筛候选 → 只对候选补抓 JD 详情
* **岗位去重**：归一化标题 + 去掉 URL 跟踪参数（`utm_*`/`spm`/`recommendCode`）+ 哈希身份，
  同一岗位重复抓到只更新不新增
* 中文方向会自动扩展英文同义词（`python后端` → `python backend`、`backend engineer`）

### 2. 薪资行情统计（真的算，不是编的）

招聘网站的薪资写法极其杂乱，先归一化再统计：

```
25-40K·14薪       → 月薪 25~40K，发 14 个月
2-3万/月           → 月薪 20~30K
20-40万/年         → 月薪 16.7~33.3K
8000-12000元/月   → 月薪 8~12K
$120,000 a year   → 美元，单独统计不与人民币混算
薪资面议           → 丢弃（但计数保留）
```

输出月薪的**中位 / 平均 / P25 / P75 / 区间 / 年薪中位 + 样本量**，
并和你填的期望薪资对比，给出「高于/低于/基本吻合」和具体建议。

> 诚实地说明：**校招官网通常不公开薪资**，所以样本可能偏少。
> 样本 < 5 条时会明确标注「参考价值有限」；一条都没有时直接说「无法统计」，
> 绝不会拿假数据凑一个平均值出来。

### 3. 用户专属知识库

素材全部来自你自己的数据，落到独立的 Chroma 集合 `personal_kb`（与公共题库物理隔离）：

| 素材 | 来源 |
|------|------|
| 你的简历 | 上传的 PDF/TXT，切成块 |
| 目标岗位 JD | 你从抓取结果里选中的那个 |
| 同类岗位 JD | 同城市同方向抓到的其他岗位（最多 12 条，优先有薪资和 JD 正文的） |
| 相关面试题 | 从内置题库按「简历 + 目标岗位」检索出来的同类题 |

模拟面试、出题、简历优化、评分**都优先检索这个库**，没有才退回公共库。

### 4. 模拟面试

* 出题同时结合**你的简历经历**和**目标岗位要求**（实测效果：会说「你简历里提到用 Chroma 做 RAG…而京东这个岗位面向零售全场景 Agent…」）
* 逐题作答，面试官给评价 + 下一题
* 长上下文用**滑动窗口 + 滚动摘要**管理，可以聊很多轮不丢上下文
* 结束后生成结构化报告（总评 / 维度得分 / 亮点 / 待改进 / 复习方向）

### 5. 防幻觉

* **检索闸门**：向量相似度与关键词信息量都不过线 → 直接拒答，不硬凑
* **Prompt 硬约束**：只能依据参考资料作答，禁止编造数字、公司、时间、薪资
* **低 temperature**（默认 0.2）
* **强制引用 + 编号校验**：不存在的引用编号会被剔除并告警，引用覆盖率折算成可信度分数
* 简历优化会明确声明「以下内容均基于原简历已有事实，未新增任何原简历中不存在的经历」

## 六、为什么 exe 只有 125MB

* **不打包 Chromium**：Playwright 用 `channel="msedge"` 驱动系统自带的 Edge
  （Windows 10/11 都预装），省掉 150MB+。找不到 Edge 会自动退到 Chrome。
* **不打包 Streamlit**：前端是原生 HTML/CSS/JS 单页应用，由 FastAPI 直接托管。
* **向量化是离线的**：内置字符 n-gram 哈希 TF-IDF，不需要联网下载 embedding 模型——
  这点对打包特别重要，否则首次运行下载模型失败就会直接跑不起来。

## 七、常见问题

**Q：一定要联网吗？**
抓岗位和调用大模型必须联网。其余功能（知识库检索、引用校验、界面）都能离线工作。

**Q：抓不到我关心的公司怎么办？**
两种办法，按公司情况选：

1. **该公司的招聘页有公开 JSON 接口**（推荐，稳定且快）——在「岗位来源」里
   复制一份 `tencent` 的配置，改 `endpoint`、`params`/`body` 和 `field_map` 的字段名即可，
   不用改代码。怎么找接口：打开招聘页 → F12 → Network → 找返回岗位列表的那个请求。
2. **没有可用接口，只有渲染出来的页面**——填该公司的**职位列表页地址**，
   程序会用系统 Edge 渲染并自动识别岗位卡片，然后只抓职位名命中你方向的岗位。
   个别站点结构特殊时，可以补一个 `item_selector`（岗位卡片的 CSS 选择器）。

**Q：薪资样本为什么这么少？**
公司官网和校招站基本不公开薪资。牛客网有结构化薪资字段，
**前程无忧 51job** 的 `jobSalaryMin`/`jobSalaryMax` 是数字字段（元/月），
这两个是目前最可靠的中文薪资来源。**样本不足时程序会明确告诉你，不会编造。**

**Q：51job 显示「触发了人机验证」怎么办？**
它的请求频率一高就会要求滑动验证，此时程序会跳过该来源并如实说明。
稍等一会儿重试通常就恢复了；也可以先在「岗位来源」里关掉它，
其余来源不受影响。**它只影响这一个来源，不会让整个抓取失败。**

**Q：换了目标岗位要重新建库吗？**
要。界面会提示。换了岗位不重建，面试题还是围绕旧岗位出的。

**Q：怎么换台电脑 / 怎么备份？**
整个文件夹拷走即可。要备份数据就备份 `data/` 目录；要清空重来就删掉它。

**Q：能用 MySQL 吗？**
可以，单机版默认 SQLite 是为了免除依赖。装 `aiomysql` 后把 `.env` 里的
`DATABASE_URL` 改成 `mysql+aiomysql://...` 即可，连不上会自动回退 SQLite。

## 八、v2 → v3 的变化

| | v2 | v3（当前） |
